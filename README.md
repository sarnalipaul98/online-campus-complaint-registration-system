# Online Campus Complaint Registration System

## 1. Project Overview
The **Online Campus Complaint Registration System (OCCRS)** is a web-based application developed to simplify and manage the complaint registration process within an educational institution.
The system allows students to submit complaints online, track their progress, communicate with administrators and managers, and provide feedback after resolution.
It provides separate dashboards for students, administrators, and managers to ensure efficient complaint handling and monitoring.

## 4. User Roles
### Student
- Student login and password management.
- Register campus complaints.
- Upload supporting documents or images.
- View submitted complaints.
- Track complaint progress.
- Communicate with managers.
- View resolved complaints.
- Submit ratings and feedback.

### Administrator
- Secure admin login.
- View all registered complaints.
- Monitor pending and resolved complaints.
- Filter, search, and sort complaints.
- View department-wise complaint statistics.
- View complaint analysis charts.
- Send messages to students.
- Communicate with managers.

### Manager
- Manager login.
- View and manage complaints.
- Monitor complaint progress.
- Update complaint progress stages.
- Resolve complaints.
- Upload proof of resolution.
- Communicate with students and administrators.
- View feedback.

## 5. Main Features
- Role-based login system.
- Online complaint registration.
- Complaint document and image uploads.
- Complaint status tracking.
- Progress tracking with percentage updates.
- Student-manager messaging.
- Admin-manager communication.
- Complaint resolution with proof.
- Student feedback and rating system.
- Department-wise complaint analysis.
- Month-wise complaint graphs.
- Search, filtering, and sorting.
- Light and dark theme support.
- Responsive interface for mobile and desktop.

## 6. Complaint Progress Stages
The system tracks complaints through six stages:

1. Complaint Submitted – 0%
2. Received By Manager – 20%
3. Verified By Manager – 40%
4. Work In Progress – 60%
5. Finalizing Work – 80%
6. Solved Successfully – 100%

## 7. Database
The application uses **MySQL** to store application data.
Main database tables include:
- `users`
- `complaints`
- `student_passwords`
- `messages`
- `admin_messages`
- `admin_manager_chat`
